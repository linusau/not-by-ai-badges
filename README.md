# Not By AI Badges

All the official **Not By AI** badge SVGs, collected from [notbyai.fyi](https://notbyai.fyi/) — free badges to showcase human-made content.

These badges tell visitors that your work was created by a person, not an AI. Add them to your website, README, GitHub profile, or app.

## Badges

Every badge comes as an SVG. Color variants differ per badge type — some are only available in **white** (light background), some in **black** (dark background).

| Color | Purpose | Path |
|-------|---------|------|
| `white/` | Use on **light** backgrounds (text is dark) | `white/<verb>-by-human-not-by-ai-white.svg` |
| `black/` | Use on **dark** backgrounds (text is light) | `black/<verb>-by-human-not-by-ai-black.svg` |
| `not-by-ai.svg` | Standard "Not By AI" logotype | root |
| `not-by-ai-registered.svg` | Registered (®) logotype | root |

### Writer badges — for text-based content
`written` · `authored` · `created` · `researched` · `scripted`
*(good for blog posts, essays, books, research, code)*

### Artist badges — for visual/audio content
`painted` · `drawn` · `illustrated` · `photographed` · `sculpted` · `animated` · `designed` · `composed` · `crafted` · `sung`
*(good for artwork, illustrations, paintings, music, animations)*

### Producer badges — for produced content
`produced` · `filmed` · `arranged` · `developed` · `narrated` · `performed`
*(good for films, songs, apps, podcasts)*

## Usage

Copy an SVG into your project, or hotlink it from this repo (GitHub serves raw files fine):

```html
<img src="https://raw.githubusercontent.com/linusau/not-by-ai-badges/main/white/written-by-human-not-by-ai-white.svg" alt="Written by human, not by AI" width="200">
```

### Markdown (GitHub README)

```markdown
![Written by human, not by AI](https://raw.githubusercontent.com/linusau/not-by-ai-badges/main/white/written-by-human-not-by-ai-white.svg)
```
